# Banking System in Java

A console-based banking system implemented in Java, demonstrating core Object-Oriented Programming concepts. Users can create Current or Savings accounts, log in, deposit, withdraw, and calculate interest for savings accounts. This project is beginner-to-intermediate friendly and showcases practical OOP skills.

## Features
- Create Current and Savings accounts
- Deposit and Withdraw money
- Check account balance
- Add interest for Savings accounts
- Menu-driven console interface with nested menus
- Demonstrates OOP concepts: classes, inheritance, constructors, arrays of objects, methods, and conditional logic

## How to Run
1. Open terminal/command prompt in the project folder
2. Compile all Java files:
   ```bash
   javac *.java
